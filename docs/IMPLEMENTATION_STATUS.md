## Remote CI

The GitHub Actions workflow runs remotely on every push and pull request. **On `main` at `92dec74` ([run 38973025420](https://github.com/EltonChang1/Assay/actions/runs/38973025420)), every job passes.** The Linux `sandbox` job passes **all 28 real Docker cases** on GitHub's hosted `ubuntu-latest` runner. The foundation job passes on `ubuntu-latest` (397 tests passed, the 28 Docker cases skipped) and `windows-latest` (396 passed; the Docker cases and the POSIX-only snapshot-mode test skipped), with both optional extras required, plus Ruff, strict mypy, `doctor`, the 10 trusted SQL regressions, and the source/wheel build.

Earlier runs, through `7ce5d22` ([run 38969948625](https://github.com/EltonChang1/Assay/actions/runs/38969948625)), passed the foundation job but failed **11 of 28 Docker cases**: the exact-decimal correctness queries, row-limit truncation, CPU throttling, memory/disk/process exhaustion, and stdout/stderr overflow. Each failed because the worker returned `invalid_bundle` where a useful query was expected. The pre-Phase 4 `ce62094` run failed identically.

**Cause and fix.** The gateway staged each frozen input snapshot in a `tempfile` directory, which is created owner-only (`0700`), then renamed it into place. Linux bind mounts preserve host ownership and modes, so the worker's fixed UID 10001 could not enter `/data`; the worker reports that `PermissionError` as `invalid_bundle`. Docker Desktop's Windows file sharing does not enforce these modes, so local runs passed. Tests that mount a `write_public_bundle` directory directly, or never read tables, were unaffected. A Linux reproduction (the real gateway code freezing a snapshot as UID 1001 on ext4, then the pinned worker image reading it with production flags) returned `invalid_bundle` before the fix and USD 200.00 after it. The fix gives the snapshot tree explicit `0755`/`0644` modes before it becomes visible, regardless of umask; a new POSIX-only gateway test fails on Linux without it. The full enabled local suite on the fixed tree passed 424 tests, with that test skipped on Windows, and hosted CI then passed every job as above.
